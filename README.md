# 小丑牌存档生成器 · Balatro Save Generator

作者：[衔榆](https://www.gexu.games/)

网页版 Balatro（小丑牌）开局存档生成器：自定义牌组、赌注与开局参数，一键生成**第一关（第 1 底注、盲注选择界面）**的运行存档 `save.jkr`，放入游戏存档目录后即可从主菜单「继续游戏」进入。

> 适用游戏版本：**Balatro 1.0.1o（PC）**，其他版本未验证
>
> 🚧 **项目开发中**，功能持续补充，欢迎关注。

## ✨ 功能

当前已实现：

- **15 种牌组**自由选择：红 / 蓝 / 黄 / 绿 / 黑 / 魔法 / 星云 / 幽灵 / 废弃 / 方格 / 黄道 / 彩绘 / 浮雕 / 等离子 / 古怪
- **8 级赌注**选择：白注 → 金注（红注起附带对应修饰规则）
- 开局参数自定义：**出牌数、弃牌数、手牌上限、小丑槽位、消耗牌槽位、起始金币、游戏种子**（默认值随牌组变化：彩绘手牌 10 / 小丑槽 4、黑色小丑槽 6 / 出牌 3、星云消耗牌槽 1 等）
- **牌堆按牌组类型生成并写入存档**：废弃牌组 40 张（无人头牌）、方格牌组 26 黑桃 + 26 红桃、古怪牌组按种子随机点数花色；牌堆顺序也与真实开局一致（游戏的开局洗牌 `pseudoshuffle(pseudoseed('shuffle'))`）
- 「修改牌组」弹窗查看完整牌堆，底部**「重置」**按钮按当前牌组规则重建默认牌堆（古怪牌组按当前种子重新生成）。**切换牌组或改种子不会自动刷新牌堆**——牌堆与所选牌组不一致时，导出完成的提示会标注「牌堆未重置」
- 牌组的「基础卡牌」统计与扑克详情的花色使用游戏原生 UI 图标（A / 人头牌 / 数字牌 / 四花色）
- 牌面支持逐张修改：**左键单击打开扑克详情**（中间大图展示牌面，左右五组切换箭头：点数 / 花色 / 增强（玻璃牌等）/ 蜡封（红蜡等）/ 版本（闪箔 / 镭射 / 多彩）；改动先记在副本上：**「确定」写回这张牌、「创建新的」按当前设置另存一张（不动原牌）、「取消」丢弃**；点遮罩关闭等同取消）。**版本不含负片**：负片只作用于小丑与消耗品（游戏里给扑克牌加版本的 Aura 与标准包都强制排除负片，且负片的唯一效果是「不占槽位」，对牌堆里的牌没有意义）
- 详情里的当前值**配色与游戏一致**：增强 / 蜡封 / 版本有值时按游戏配色填充色块（增强紫蓝 `#8389dd`、金蜡封金色、紫蜡封紫色…），配色取自游戏的 `G.BADGE_COL` 与分类色表；**版本色块还会随游戏节奏呼吸**（游戏主循环每帧改写 `G.C.DARK_EDITION`，周期约 4.8 秒，在暖灰与蓝之间往返）
- **版本效果由移植自游戏的 shader 实时渲染**：四个版本的 `*.fs` 从游戏 GLSL 移植到 WebGL（`ui/cardShader.ts`），全部牌面共用一个 WebGL context；详情弹窗里的牌满帧动画（闪箔金属流光、镭射网格、多彩流动彩虹、负片冷色暗调），牌组编辑器里的 52 张牌用一次渲染的静态快照。顶点倾斜（跟随鼠标的 3D 视差）按项目定案不做
- 牌组弹窗底部另有蓝色「**创建卡牌**」按钮：打开同一个详情弹窗，但没有「确定」，只有「取消 / 创建新的」（新建牌默认黑桃 A，可先切好点数/花色/增强/蜡封再创建）/ **右键单击删除**该张，统计与牌堆张数实时更新（至少保留 1 张）
- 增强与蜡封会写进存档：增强改写 `save_fields.center`、`label` 并按游戏的 `Card:set_ability` 重算 `ability`；蜡封写入 `seal` 字段
- 「**消耗牌**」入口在牌组与赌注选择的下方（**已写入导出存档**，与真机样例逐字段一致）：显示「消耗牌 N / 槽位数」与已有消耗牌；已有牌**水平排列**在一块黑底牌区里，张数多时按可用宽度自动加大重叠。左键点某张即移除；「**新增消耗牌**」按钮打开**图鉴弹窗**——按**塔罗牌 / 星球牌 / 幻灵牌**标签筛选（默认塔罗牌），牌池固定两行、每行 6 张，左右箭头翻页（没有滚动条），**左键点某张即选中并自动关闭弹窗**（可重复，已选的显示 ×N 角标），「返回」表示不选；鼠标悬停某张时才在**该牌旁边**浮出一个说明框（自动选左右侧，平时不占位，含牌型等级、增强牌名等 `#N#` 数值）。数量上限就是参数面板的「消耗牌」槽位数：**满员时「新增消耗牌」按钮置灰不可点**，移除一张或调大槽位数后恢复
- 「**负片开启/负片关闭**」开关在图鉴弹窗的操作行：开启时牌池按负片样式预览，**此刻点选的牌带负片**加入（入口以负片样式渲染、导出写负片 edition），关闭时点选的牌不带；**负片每张使上限 +1**（与游戏一致：2 槽 + 1 张负片 → 计数 1/3）；开关在同一会话内保持（关闭弹窗、切换牌组都不重置），刷新页面后恢复默认关闭
- 一键**导出 `save.jkr`**
- 「**小丑牌**」入口在消耗牌下方（**已写入导出存档**，与真机样例逐字段一致）：横向贯通左右两列——左缘与消耗牌入口对齐、右缘与种子组件对齐；显示「小丑牌 N / 槽位数」与已有小丑，黑底牌区水平排布、牌多时自动重叠，**左键点某张即移除**；「**新增小丑牌**」按钮打开图鉴弹窗——150 张小丑按**稀有度页签**（普通/罕见/稀有/传奇，游戏 `G.C.RARITY` 配色）分组，牌池两行 × 6 张翻页，悬停浮出说明框（`#N#` 数值按游戏源码的取值逻辑静态求值，个别依赖局内状态的行会省略）
- 「**优惠券**」入口在右列参数面板下方（消耗牌右侧）：30 张券的图鉴弹窗（点未拥有的券即选入，已拥有置灰；**选加强版自动连带基础券**，移除基础券级联移除加强版）；**牌组自带券**（魔法水晶球 / 星云望远镜 / 黄道三张）随牌组切换自动带上、不可移除；写入导出存档的 `used_vouchers`——水晶球 +1 消耗槽、反物质 +1 小丑槽、抓手/油漆刷/常弃常新等结构性效果全部按游戏规则落盘（续档不重放券效果，故由工具直接写入）
- **点图鉴里的小丑牌不直接加入**，而是打开**单卡定制弹窗**（与扑克创建弹窗同款布局）：中间大图实时预览，左右箭头切换 **版本**（无/闪箔/镭射/多彩/负片）与贴纸——**永恒/易腐互斥**（同一组循环切换，不容贴纸的小丑自动禁用）、**租用**独立可叠加；贴纸按游戏原素材**整卡覆盖**在牌面上（入口与弹窗一致）；「创建」入列，「返回」丢弃。**负片每张使上限 +1**（5 槽 + 1 张负片 → 计数 6/7），**租用小丑存档价 $1**（游戏内每回合另扣租金 $3）

古怪牌组的随机数复刻了 Balatro 实际使用的 LuaJIT Tausworthe 伪随机与 `pseudohash/pseudoseed` 体系，因此**同一组「牌组 + 种子」的牌堆与游戏内开局完全一致**（含 NaN 坏种子会得到整副同名牌的表现）。

尚未实现、后续版本补充：优惠券、牌组的非数值规则（星云/黄道牌组的起始优惠券、幽灵牌组的幽灵牌出现率、绿牌组无利息等；魔法牌组的水晶球券已随消耗牌一并写入）。完整路线图见 [PROJECT_SPEC.md](./PROJECT_SPEC.md) 第 6 章。

## 📖 使用方法

1. 在网页中选择牌组与赌注，按需调整出牌 / 弃牌 / 金币 / 种子；
2. 点击「**导出存档**」，下载得到 `save.jkr`；
3. **关闭游戏**（若游戏内有进行中的对局，「继续游戏」会被占用）；
4. 将文件放入 `C:\Users\<用户名>\AppData\Roaming\Balatro\<存档位 1~3>\`，覆盖同名文件——**覆盖前先备份原存档**；
5. 启动游戏，主菜单点击「**继续游戏**」。
