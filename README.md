# 小丑牌存档生成器 · Balatro Save Generator

网页版 [Balatro（小丑牌）](https://www.playbalatro.com/) 开局存档生成器：自定义牌组、赌注与开局参数，一键生成**第一关（第 1 底注、盲注选择界面）**的运行存档 `save.jkr`，放入游戏存档目录后即可从主菜单「继续游戏」进入。

> 适用游戏版本：**Balatro 1.0.1o（PC）**，其他版本未验证
>
> 🚧 **项目开发中**，功能持续补充，欢迎关注。

## ✨ 功能

当前已实现：

- **15 种牌组**自由选择：红 / 蓝 / 黄 / 绿 / 黑 / 魔法 / 星云 / 幽灵 / 废弃 / 方格 / 黄道 / 彩绘 / 浮雕 / 等离子 / 古怪
- **8 级赌注**选择：白注 → 金注（红注起附带对应修饰规则）
- 开局参数自定义：**出牌数、弃牌数、起始金币、游戏种子**
- 一键**导出 `save.jkr`**

尚未实现、后续版本补充：各牌组专属规则的数值落地（如彩绘手牌上限 10、绿色牌组无利息等）、起始小丑、起始消耗品、优惠券、逐张定制 52 张牌……完整路线图见 [PROJECT_SPEC.md](./PROJECT_SPEC.md) 第 6 章。

## 📖 使用方法

### 生成并存入存档

1. 在网页中选择牌组与赌注，按需调整出牌 / 弃牌 / 金币 / 种子；
2. 点击「**导出存档**」，下载得到 `save.jkr`；
3. **关闭游戏**（若游戏内有进行中的对局，「继续游戏」会被占用）；
4. 将文件放入 `C:\Users\<用户名>\AppData\Roaming\Balatro\<存档位 1~3>\`，覆盖同名文件——**覆盖前先备份原存档**；
5. 启动游戏，主菜单点击「**继续游戏**」。

### 本地开发

```bash
npm install     # 安装依赖（Vite + TypeScript + vitest，运行时仅 fflate）
npm run dev     # 开发服务器（热更新）
npm test        # 单元测试（含序列化器往返强制门禁）
npm run build   # 构建纯静态产物到 dist/
```

仓库本身自包含，以上命令**不需要任何游戏文件**。仅当需要重新提取游戏数据时（`npm run gen`，一般在游戏版本更新后），才需将游戏的 `Code/` 源码目录放置在本仓库的**同级目录**下。
